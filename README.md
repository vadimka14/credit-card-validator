# Credit Card Validator

## Опис
Консольна утиліта на Go для перевірки номерів банківських карток: валідація формату, перевірка контрольної суми за алгоритмом Луна та визначення банку-емітента за префіксом номера.

## Можливості
- Інтерактивне введення номера картки (з підтримкою пробілів і дефісів у вводі)
- Валідація формату: довжина 13–19 цифр, лише числові символи
- Перевірка контрольної суми за алгоритмом Луна
- Визначення банку за префіксом номера (список банків задається у `banks.txt`)
- Зрозумілі повідомлення про помилки на кожному етапі перевірки

## Запуск
```bash
go run main.go
```

## Формат banks.txt
```
Назва банку,Префікс
```
